# 📱 Chat Multi-Instância com Integração WhatsApp API

Este projeto é uma aplicação backend em desenvolvimento que permite a criação e gerenciamento de múltiplas instâncias de chat integradas ao WhatsApp. O sistema foi pensado para atender empresas com alto volume de mensagens, oferecendo automação, escalabilidade e controle centralizado de comunicação.

---

## 📌 Visão Geral

A aplicação fornece uma API robusta para gerenciamento de instâncias de chat, permitindo a conexão com o WhatsApp através de QR Code, autenticação segura e integração com sistemas externos.

O objetivo do projeto é simular um ambiente real de atendimento automatizado e escalável, como usado em sistemas de suporte e automação comercial.

---

## ⚙️ Funcionalidades

- 🔄 Criação e gerenciamento de múltiplas instâncias de chat
- 📲 Geração de QR Code para conexão com WhatsApp
- 💬 Envio e recebimento de mensagens via API
- 🔐 Autenticação segura com Spring Security e JWT
- 📡 Integração com API REST própria
- 🧩 Estrutura preparada para integração com sistemas externos
- 🚀 Base para automações, campanhas e atendimento em escala

---

## 🛠️ Tecnologias Utilizadas

- Java 17+
- Spring Boot
- Spring Security
- JWT (JSON Web Token)
- REST API
